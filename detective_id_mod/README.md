# Detective ID Animation — Minecraft 1.12.2 Forge

Hold light-blue dye (metadata 12) or cyan dye (metadata 6) in the main hand and right-click.

The mod replaces the first-person hand rendering while the sequence is active. The arm uses the current player's skin texture. The hand rises from below, then the supplied detective ID opens: the animation is 0.625 seconds long and bone "1" rotates to -135 degrees at 0.125 seconds.

The supplied Blockbench geo, animation JSON and texture are included in the project.
