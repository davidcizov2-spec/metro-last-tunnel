# D.Ch AI Local — Windows EXE без API-ключа

## Скачать EXE
Открой GitHub Actions в этом репозитории. Выбери запуск «Build D.Ch AI Local EXE» и скачай артефакт «DChAI_Local-Windows-EXE».

## Установка локальной модели
1. Установи Ollama для Windows: https://ollama.com/download/windows
2. Открой командную строку и выполни: ollama run qwen2.5:3b
3. Дождись загрузки модели и оставь Ollama работающей.

## Использование
- Запусти DChAI_Local.exe.
- Нажми «Говорить», чтобы задать вопрос голосом.
- «Игровая панель» включает компактное окно поверх обычных окон.
- Esc возвращает обычное окно.
- Для использования поверх Minecraft выбери оконный режим или «без рамки».

## Важно
Чат отвечает локально через Ollama и не использует API-ключ. Языковая модель скачивается отдельно и не включена в EXE. Голосовое распознавание использует интернет и не требует отдельного API-ключа. Оверлей может не отображаться поверх игр в эксклюзивном полноэкранном режиме.
